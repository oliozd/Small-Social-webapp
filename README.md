Welcome to Small Social. This is a personal learning project.

It is a locally run social media webapp that allows a user to register their account and post, view or delete posts. 

Right now, the frontend is based entirely on streamlit. This may change with following updates.

Use this to practice your webdev skills and deepen your understanding.

Directions to run(with uv):
1.  Launch the backend from the main.py file: uv run main.py
2.  Launch your frontend with streamlit: uv run streamlit run frontend.py
3.  Paste the localhost url into your browser
4.  You must register an account before you view the feed
